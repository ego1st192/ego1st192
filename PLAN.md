# План: личный ИИ-ассистент («свой Джарвис»)

> Рабочее имя проекта будет выбрано позже. В коде пока используется `assistant`.

## Цель

Персональный ИИ-агент, который:
- знает меня (цели, привычки, проекты, предпочтения) и помнит прошлые разговоры;
- анализирует мои действия и данные (календарь, задачи, активность);
- сам предлагает решения, планирует день, напоминает и разбирает итоги;
- доступен везде: iPhone, Windows-ПК, голосом через Siri.

## Исходные условия

| Что есть | Как используем |
|---|---|
| iPhone (Mac нет) | PWA-приложение на экране «Домой» + Siri Shortcut + (опц.) Telegram |
| Windows 10/11 | Разработка: VS Code, Python, Docker Desktop / WSL2 |
| NAS в колледже (разрешено использовать) | Продакшен-сервер 24/7 в Docker |

## Архитектура

```
 iPhone: PWA / Siri Shortcut / Telegram        Windows: браузер (та же PWA)
                    │ HTTPS
                    ▼
        Tailscale (приватно) / Cloudflare Tunnel (публичный HTTPS для push)
                    │
                    ▼
 NAS (Docker Compose)
 ├── api        — FastAPI: чат, авторизация, REST для клиентов
 ├── agent      — ядро: Claude API + инструменты (tool use) + системный промпт
 ├── memory     — Postgres + pgvector: профиль, события, смысловой поиск
 ├── scheduler  — бриф 8:00, рефлексия 21:00, недельный разбор, напоминания
 ├── web        — PWA (чат, голосовой ввод, push-уведомления)
 └── backup     — шифрованные бэкапы БД (копия вне NAS)
```

Принцип: **мозг и память живут на сервере**, клиенты — только «лицо».
API-ключи никогда не попадают в приложение или в git.

## Стек

- **Backend:** Python 3.12, FastAPI, `anthropic` SDK, SQLAlchemy, APScheduler
- **БД:** Postgres 16 + pgvector (на старте можно SQLite)
- **Frontend:** PWA (HTML/TS, Service Worker, Web Push, Web Speech API)
- **Голос:** диктовка iOS / Whisper (распознавание), TTS для ответов
- **Инфраструктура:** Docker Compose, Tailscale, Cloudflare Tunnel
- **Интеграции:** через инструменты агента / MCP (календарь, почта, задачи, заметки, веб-поиск)

## Этапы

### Этап 0. Подготовка (1 вечер)
- [ ] Выбрать имя ассистента
- [ ] Получить API-ключ Claude (console.anthropic.com), установить лимит расходов
- [ ] Установить на Windows: Git, VS Code, Python 3.12, Docker Desktop (WSL2)
- [ ] Узнать модель NAS, проверить поддержку Docker и объём RAM
- [ ] Структура репозитория, `.env.example`, `.gitignore`

### Этап 1. MVP: ассистент, который меня помнит (1–2 выходных)
- [ ] FastAPI-сервер с эндпоинтом `/chat`
- [ ] Системный промпт: роль, стиль общения, правила
- [ ] Профиль пользователя (`profile`) — агент сам дополняет его через инструмент `remember`
- [ ] История диалогов в БД
- [ ] Простая авторизация (токен) — сервер доступен только мне
- [ ] Запуск локально на Windows через `docker compose up`

### Этап 2. Лицо на iPhone (1 неделя)
- [ ] PWA: чат, история, установка на экран «Домой»
- [ ] Голосовой ввод
- [ ] Siri Shortcut «Привет, Siri, <имя>»: диктовка → запрос → озвучка ответа
- [ ] Развёртывание на NAS + Tailscale, доступ с iPhone

### Этап 3. Руки: инструменты (1–2 недели)
- [ ] Задачи и проекты (своя таблица или Todoist / Notion)
- [ ] Календарь (Google / Outlook)
- [ ] Заметки и файлы на NAS (чтение, поиск)
- [ ] Веб-поиск
- [ ] Почта: чтение и черновики; **отправка только после подтверждения**

### Этап 4. Проактивность (1 неделя)
- [ ] Cloudflare Tunnel + Web Push уведомления
- [ ] Утренний бриф: погода, расписание, приоритеты дня
- [ ] Вечерняя рефлексия: что сделано, что перенести
- [ ] Умные напоминания, дедлайны

### Этап 5. Глаза: анализ действий (2+ недели)
- [ ] ActivityWatch на Windows → отправка статистики на сервер
- [ ] Данные iPhone (экранное время, шаги, сон) через Shortcuts-автоматизации
- [ ] Долговременная память: pgvector, сжатие старых диалогов в факты
- [ ] Недельный отчёт: куда ушло время, прогресс по целям, советы

### Этап 6. Надёжность и полировка (постоянно)
- [ ] Шифрованные бэкапы БД вне NAS (облако / ПК)
- [ ] Логи, мониторинг, алерты «сервер упал»
- [ ] Готовность к переезду на VPS одной командой (NAS колледжа может стать недоступен)
- [ ] Голос ответов (TTS), личность и стиль

## Безопасность и приватность

- Секреты только в `.env` на сервере, `.env` в `.gitignore`.
- Доступ к серверу — только через Tailscale или с токеном; никаких открытых портов.
- Данные в БД и бэкапах — шифровать (NAS принадлежит колледжу).
- Опасные действия (отправка писем, удаление, платежи) — только после явного подтверждения.
- Лимит расходов на API в консоли.
